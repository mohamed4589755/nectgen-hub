Diploma Plan

What You Will Learn

39 technical sessions (3 hours each · 2 sessions per week · about 4.5 months) plus 17 Soft Skills sessions (50 hours).

Module 01

Introduction to Data Analysis

1 Session · 3 Hours

Foundations of data-driven decision making, analytics lifecycle, business problem framing, and setting up your end-to-end analytics environment.

Module 02

Excel

7 Sessions · 21 Hours

Master spreadsheet data cleaning, advanced formulas and lookups, dynamic pivot tables, KPI tracking, and interactive business reporting dashboards.

Module 03

SQL

6 Sessions · 18 Hours

Query relational databases confidently using complex joins, aggregations, subqueries, common table expressions (CTEs), and analytical window functions.

Module 04

Tableau

5 Sessions · 15 Hours

Transform raw datasets into compelling visual stories with calculated fields, interactive filters, parameters, and executive Tableau dashboards.

Module 05

Power BI

4 Sessions · 12 Hours

Build enterprise business intelligence solutions using Power Query data modeling, DAX measures, KPI visuals, and executive Power BI reports.

Module 06

Looker Studio

2 Sessions · 6 Hours

Connect live cloud data sources, configure automated data blending, and publish shareable web-ready interactive dashboards.

Module 07

Python

8 Sessions · 24 Hours

Write clean Python code for data wrangling, exploratory data analysis (EDA), statistical aggregation, and automated reporting workflows.

Module 08 · Hands-on Practice

Projects & Wrap-up

6 Sessions · 18 Hours

Extensive hands-on practice across Excel, SQL, Tableau, Power BI, Looker Studio, and Python to build a job-ready analytics portfolio.

  • 10 Practical Tasks
  • 10 Real-World Projects
  • Full Stack: Excel · SQL · BI Tools · Python
