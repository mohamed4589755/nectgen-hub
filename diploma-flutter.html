Program Roadmap

What You Will Learn

12 weeks of structured technical training across 3 intensive months, 4 full-scale mobile applications, followed by a dedicated Soft Skills month (130 hours in total).

Month 1 · Weeks 1–4

Flutter Basics & Local Storage

Build core UI foundations, smooth animations, multimedia integration, local persistence with SharedPreferences, Sqflite, and Hive, and architectural patterns (MVC, MVVM & Clean Architecture).

  • Week 1: Widgets & Widget Tree, Custom Widgets, Navigation & Passing Data Between Screens
  • Week 2: Responsive UI, Animations, Multimedia (Images, Audio & Video)
  • Week 3: Introduction to Databases, Online vs Offline Databases, SharedPreferences, Sqflite & CRUD Operations
  • Week 4: Hive Database & Type Adapters, Design vs Architectural Patterns (MVC, MVVM & Clean Architecture) & Practical Project: ToDo App
Month 2 · Weeks 5–8

State Management & Networking

Master scalable app state with Provider, Cubit & Bloc, dependency injection with GetIt, Repository Pattern, REST APIs, and client-server cloud architectures.

  • Week 5: State Management Fundamentals, Provider (ChangeNotifier, Consumer, watch & read) & Practical: ToDo App with Provider
  • Week 6: Cubit & Bloc (Events, States & Bloc Widgets), Dependency Inversion vs Injection, GetIt & Repository Pattern
  • Week 7: Networking Fundamentals, REST APIs & HTTP Methods, JSON Parsing & Model Classes, Async/Await & Error Handling, Practical Project: News App using HTTP
  • Week 8: Client-Server Architecture, Servers vs Cloud Providers, Introduction to Firebase & Supabase, API Integration & Pagination
Month 3 · Weeks 9–12

Supabase & Advanced Flutter

Ship full-stack mobile applications powered by Supabase Authentication, PostgreSQL CRUD, Row Level Security, Realtime streams, Storage, Localization, Google Maps, and SOLID Clean Architecture.

  • Week 9: Supabase Setup, Supabase Authentication (Sign Up, Sign In & Sign Out), Session Management & Chat App: Authentication
  • Week 10: Supabase Database & CRUD, Tables & Relationships, Row Level Security (RLS), Supabase Realtime & Chat App: Real-Time Messaging
  • Week 11: Supabase Storage, File Upload & Image Handling, Localization (Arabic & English, RTL) & Google Maps Basics
  • Week 12: SOLID Principles, Dependency Injection & Clean Architecture, E-Commerce App Integration (Products, Categories, Cart & Orders) & Final Project Review
4 Main Projects

Real-World Portfolio Applications

Graduate with 4 complete mobile applications covering local persistence, state management, REST APIs, real-time backends, and production Clean Architecture.

  • 01. ToDo App (Months 1–2) — Local Storage & Provider
  • 02. News App (Month 2) — REST APIs & HTTP Networking
  • 03. Real-Time Chat App (Month 3) — Supabase Auth, RLS & Realtime
  • 04. E-Commerce App (Month 3) — Clean Architecture, Products, Categories, Cart & Orders
After 4 Months

Soft Skills Month

A dedicated career readiness and soft skills month following the technical curriculum to prepare graduates for mobile engineering roles, technical interviews, and freelancing, culminating in a Verified NextGen Certificate of Completion.
