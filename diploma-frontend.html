Four-Level Skill Tree

What You Will Learn

Four progressive levels, one per month, each ending with a portfolio project, followed by a 24-hour Soft Skills month.

Level 1 · Month 1

Structure & Style

Build the visual shell and establish the structural foundation and visual language of the web. Design fluid interfaces that adapt across Desktop (CSS Grid), Tablet (Flexbox), and Mobile (stacked via Media Queries), using raw HTML/CSS media queries and Bootstrap utility classes.

  • HTML Fundamentals: Semantic tags, forms, tables, links, and page structure
  • CSS Styling: Selectors, box model, positioning, animations
  • Bootstrap: Grid systems, components, and utility classes
  • Capstone: Responsive Website (fictional tech product landing page with Features, About, and Contact sections)
Level 2 · Month 2

Logic & Data

Make the shell think and react, and connect the interface to the outside world through APIs. A user action triggers a JavaScript event, which sends an API request to fetch or send data, and the DOM updates the screen without reloading the page.

  • Fundamentals: Variables, data types, operators, conditions, loops, and functions
  • Advanced Basics: Arrays, objects, Object-Oriented Programming (OOP), and ES6 features
  • Interaction: DOM manipulation, event listeners, and CRUD operations
  • Capstone: JavaScript CRUD Application (task/item management with search, add, status, and update/delete actions)
Level 3 · Month 3

Modern Architecture

Scale development with industry-standard component architecture. Move from traditional DOM manipulation, which is hard to scale and repetitive, to reusable, isolated React components (NavBar, UserCard, DataTable, Footer) with self-contained logic and fast Virtual DOM updates.

  • React Core: Virtual DOM, Component Lifecycle, Props, and State (useState)
  • Ecosystem: React Router, Axios, and Tailwind CSS
  • Advanced Logic: Custom Hooks and global state via Context API
  • Project: React CRUD Application (dashboard and data table management with add and update actions)
  • Project: Social Media Platform with Header, Sidebar (secure login/signup using Protected Routes and Context API user profile), and Feed components (reusable Posts with Create, Edit, and Delete mapped to an API)
Level 4 · Month 4

Enterprise Mastery

Enforce strict type safety and server-side rendering to write bulletproof, industry-standard code for enterprise software.

  • TypeScript: Strict types, interfaces, and catching errors before the code runs
  • Next.js: Server-side rendering (SSR), advanced dynamic routing, and professional project structure
  • State & Data: Redux for global state and React Query for server state
  • Final Project: Next.js E-Commerce Application: Browse Products, Product Details, Add to Cart & Update, Secure Checkout, with API Integration & Authentication
